Cryo Dashboard v0.3.0

This dashboard visualises cryogenic performance data derived from NIST reference data for superconducting / cryogenic LINAC systems. It includes method-comparison panels, parameter sweeps, and trend analysis.

📋 Dashboard Features (v0.3.0)

  • Method comparison panel (clean layout)
  • NIST-sourced cryogenic fluid properties
  • Interactive parameter exploration
  • Trend analysis and visualisation
  • Standalone — no backend or server required

🚀 How to deploy your dashboard files here

  1. Copy your dashboard HTML/JS/CSS files into the cryo_dashboard_v0_3_0/ folder of this repository.
  2. Make sure the main entry point is named index.html (it replaces this placeholder page).
  3. Push to the main branch — GitHub Actions will automatically redeploy to GitHub Pages within ~60 seconds.
  4. Visit https://gbogeb.github.io/Q_engineering_tools/cryo_dashboard_v0_3_0/ to verify the live dashboard.
