🚀 First Time Here? Enable GitHub Pages Once

When hosted on GitHub Pages, all dashboards open directly — no Python, no server, no install. One person sets this up once; everyone else just opens the link.

  1. Go to the GitHub repository → Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: feature/method-comparison-panel (or main after merge) · Folder: / (root)
  4. Click Save — Pages URL appears within ~1 minute
  5. Bookmark: https://gbogeb.github.io/document-organization-system/cryo_dashboard_v0_3_0/cryo_dashboard_v0_3_0/index.html

Detailed steps: docs/GITHUB_PAGES_PUBLISH_GUIDE.md

⚠️ When HTML is NOT Enough — Use Python

  • Layered wall with T-dependent k — requires iterative solver for interface temperatures
  • Large parameter sweeps (100+ materials × 1000+ T points)
  • Optimization (minimize heat-load subject to constraints)
  • Uncertainty quantification and Monte Carlo simulation
  • Integration with CAD/FEA tools or experimental data
