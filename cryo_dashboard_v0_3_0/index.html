Vapour Pressure Model Comparison — He-4
Three models are compared for He-4 saturation pressure. NIST tabulated values are the reference. Clausius–Clapeyron uses a constant latent heat (ΔH_vap = 20.4 kJ/kg). The ideal-gas approximation uses P·V = n·R·T with constant molar volume. Both approximations diverge significantly outside the near-boiling region, illustrating the need for NIST reference data.

About This Dashboard

Cryo Dashboard v0.3.0 is a standalone, browser-based reference tool for cryogenic and superconducting LINAC (Linear Accelerator) system design. It provides interactive visualisation of thermodynamic properties for the two most commonly used cryogenic fluids in accelerator facilities: Helium-4 (cavity cooling, 4.2 K / 2 K) and Liquid Nitrogen (thermal shielding, 77 K).

Data sources

  • He-4: NIST REFPROP 10 / Helmholtz EOS (Ortiz-Vega et al. 2015). Key reference points cross-checked against Donnelly & Barenghi, JPCRD 27, 1217 (1998).
  • LN₂: NIST REFPROP 10 / Helmholtz EOS (Span et al. 2000). Cross-checked against NIST WebBook (webbook.nist.gov).
  • Critical constants: NIST Chemistry WebBook, SRD 69.
