📐 Property Equation Types

Polylog: k(T) = 10^( Σᵢ aᵢ · (log₁₀ T)ⁱ )
Rational: log₁₀k = (a + c√T + eT + gT^(3/2) + iT²) / (1 + b√T + dT + fT^(3/2) + hT²)
k = 10^(above), 9 coefficients (a..i)
Piecewise Logpoly: Separate coefficient sets per temperature sub-range
Used for AISI316 cp with ranges [4,50] and [50,300]
Thermal Contraction: Y(T) = a₀ + a₁T + a₂T² + a₃T³ + a₄T⁴
Optional low-T constant branch: Y(T) = f for T ≤ T_low

⚙️ Engineering Workflow

1 Select material from 10 NIST-validated options
2 Define Tmin / Tmax / cursor temperature
3 Compute k(T), cp(T), or Y(T) property curves
4 Compute dk/dT sensitivity and tangent line
5 Compute ∫k(T)dT via Trapezoid / Simpson / Romberg / Gauss-Legendre
6 Q̇ = (A/L) × ∫k(T)dT — conduction heat load output
Idempotency: Same inputs → same computed state → same plots → same exports

🔢 Integration Methods

Trapezoid
O(h²)
Composite trapezoidal rule — baseline reference
Simpson's 1/3
O(h⁴)
Composite Simpson's rule with fixed step count
Romberg
Adaptive
Richardson extrapolation to machine precision
Gauss-Legendre
O(h⁸)
4-point Gaussian quadrature per subinterval
Conduction Heat Load: Q̇ = (A/L) × ∫TcoldTwarm k(T) dT   [W]
Cooldown Energy: E = m × ∫T₁T₂ cp(T) dT   [J]
Thermal Strain: ΔL = Lref × [Y(T₂) − Y(T₁)] × 10⁻⁵   [m]

⚠️ Known Limitations & Next Steps

  • No iterative layered-wall interface solver (screening only — Python needed for T-dependent k)
  • No uncertainty propagation / Monte Carlo in-browser
  • Modular dashboard requires HTTP context (GitHub Pages or localhost — not file://)
  • Multi-material overlay limited to 4 simultaneous traces
  • Smoothing is deterministic moving average, not formal smoothing spline
