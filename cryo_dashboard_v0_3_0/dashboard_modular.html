B3 — Rate of Change / Knee Indicator

B3 plots the first derivative $dy/dT$. The knee marker is estimated from the strongest local change in slope, using a central finite-difference approximation of $|d^2y/dT^2|$. A separate $dy/dT = 0$ marker is also useful when present, because it marks a stationary point of the original curve $y(T)$, such as a local maximum or minimum.

B4 — Normalized Benchmark for Current Property (Equal Scale)

Selected material always shows normalized value, cumulative integral, and rate traces. Reference materials follow the selector above, so the legend can stay readable when overlays increase. B4 references (SS / Al / Ti / Cu / Composite) are independent of the B1 comparison overlay selector. Hover any point to see both the normalized value (0–1) and the actual physical value.
Run Calculate to generate normalized benchmark view.
